# 3D Minesweeper

A 3D Minesweeper game built with **Three.js**, **TypeScript**, and **Vite**.

The board is endless. Terrain is generated procedurally to the horizon, and
only the chunks near the player are built and drawn. You can walk a short
distance past the tiles you have uncovered; uncovering more tiles widens the
area you can reach.

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
